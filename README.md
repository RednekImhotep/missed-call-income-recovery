# Missed Call Income Recovery

AI-powered missed call response system for small businesses.

Every missed call is a missed dollar. This system catches every missed call, reads what the customer needs, and sends the right response automatically — within 60 seconds.

## How It Works

1. Customer calls and leaves a voicemail
2. AI reads the voicemail and classifies the intent
3. The right SMS response fires automatically
